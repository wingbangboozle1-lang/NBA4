Executive summary · evidence first

Originate NBA lines responsibly.

This repository contains a source-checked research plan, validation gates, a missing-information register, a review dashboard — a working reference engine that originates lines, measures correlations, runs a gate-aware leaderboard and executes a three-day slate pipeline — and, for the current slate, the official observations published row by row with links to the source documents. It has no licensed point-in-time dataset and no validated model, so every line, pick, correlation, injury-minute impact and performance field is left blank rather than guessed.

Recommended path

  1. Resolve data rights and product/jurisdiction classification before ingesting NBA statistics or awarding rewards.
  2. Select an authorized provider for historical stats, point-in-time injuries, prices and settlement data.
  3. Pre-register baselines, market definitions, validation thresholds and a chronological holdout.
  4. Measure joint probabilities and correlations from licensed, paired outcomes; issue no pick while a gate fails.
  5. Connect the licensed feed to the existing adapters, run the pipeline in shadow mode, and review the registered site suggestions (D5-14 … D5-25 are the newest) before changing the dashboard.

These are proposed controls, not evidence that a particular betting strategy works.
