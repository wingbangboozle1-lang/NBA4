Two estimators, published disagreement

Model & estimators

This page documents the reference engine's estimation stack exactly as implemented — two independent estimators, the published disagreement between them, the pinned home-court value, the market anchor, parlay and totals pricing — and shows what each part reports today. The engine is tested mechanics on synthetic fixtures; it contains no NBA-derived model values. Every live value below is either a blank [NO INPUT]/[NO BASELINE] gate result or a clearly labelled measured observation from an official document with its own link. No forecast, line, probability or pick is published here (rights gate G0; stances D-01/IR-T4 stand).

!
No model value is derived from NBA data in this repository.

Blank value cells are not zeros: the rights review (NBA Terms §9 restricts NBA Statistics used in gambling, including legal gambling) has not cleared any input for modelling use, so the engine runs with [NO INPUT] and refuses rather than guesses. The numbers that do appear on this page are measured observations published on the results page with their official links, shown here only to document what the model would pin once G0 clears.

Independent estimators and the disagreement headline

Both estimators receive the same pre-as-of authorised ledger and the same pinned home-win-rate anchor, and differ only in how they estimate team strength. The disagreement is the headline; the blend is arithmetic and is never called a confidence probability.

Home-court value, pinned to the measured home-win rate

Home advantage is not a fitted constant in this project: the point value is the exact inverse of the win-probability mapping at the measured league home-win rate, and whatever the engine uses must equal that pinned value.

Market-anchored prior, parlays and totals

The closing line is evidence, not truth: the blend weight is set by measured out-of-sample log loss, the parlay price always prints the naive product beside it, and the totals model is published beside the naive scoring average with the gap between them.
