Rest entering each window game

Definitions, stated so a reviewer can disagree: days rest is the whole-day gap to the team's previous game inside the loaded window (11/10–11/19); B2B is rest of exactly one day; 3-in-4 counts three or more games in the four-date window ending on the game date (this game included). A team whose prior game falls before 11/10 would be published as uncovered, never as rested — the coverage column of the data file records that rule.

Travel stays beside rest, not inside it

The engine measures the arena-to-arena leg from a sourced venue table and keeps its verdict separate: a leg that cannot be verified does not cancel a rest row that can, and the reverse. No travel leg is published for this window because no previous-opponent venue chain was verified for the cycle — the absence is recorded rather than estimated.
