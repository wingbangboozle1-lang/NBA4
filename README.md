# NBA4 — NBA line research dashboard

**Live site:** [https://wingbangboozle1-lang.github.io/NBA4/](https://wingbangboozle1-lang.github.io/NBA4/) (GitHub Pages publishes from `main` at the repository root; the deployment is re-checked after every merge.)

## Current status

The engine ships with synthetic fixtures and 583 passing unit tests across thirteen suites; the per-suite breakdown and this total are re-measured by `scripts/check_site.py`, which fails when the line drifts. It contains **no NBA or market data**, no trained model and no published pick.
The blocking issue is still data rights, not code. NBA's Stats FAQ states its statistics are "not available for download for either academic or personal use", and NBA.com's Terms of Use restrict NBA Statistics to "legitimate news reporting or private, non-commercial purposes" and state they "may not be used in connection with any gambling activity (including legal gambling activity)", nor with a "database ... of comprehensive, regularly updated statistics" without the Operator's express prior consent. The site now publishes **official observations only**: the 21 games inside the current three-day window (2026-11-17 – 2026-11-19), restated from the official 2026–27 schedule PDF (rows 253–273) and cross-checked against the nba.com games pages (fetched 2026-11-17), the eight settled finals of 2026-11-16, the 30-row standings split read post-11/16 games, and the 60 rows of the official 2026-11-17 10:30 AM ET injury report (revision 10:30 AM ET, retrieved 15:49 UTC; consecutive-revision diff against 10:15 AM ET), each with a link to the document and a fetch timestamp ([provenance files](data/snapshots/README.md), generated by [`scripts/build_snapshots.py`](scripts/build_snapshots.py)). Team-level rows from the official NBA.com advanced and opponent team-stat pages (30 teams each, RANK columns dropped) are published as catalogued observations with `model_inputs_status: REFUSED`. No model output, odds, or pick is published (every game carries a reason-coded NO PICK), and the engine still refuses any record whose permission flag is not set. Obtain written permission or a licensed contract, plus legal review of the product and rewards, before a betting model or public picks are considered.

## Local verification

```sh
python3 scripts/build_snapshots.py --check   # regenerate/verify the slate + injury tables from data/snapshots/
python3 scripts/check_site.py --with-tests   # page, link, table, snapshot and source-link checks + engine tests
python3 -m unittest discover -s tests -t .    # engine unit tests only
python3 scripts/run_pipeline.py \
    --inputs data/inbox-example \
    --out data/out-example \
    --now 2026-11-14T12:00:00Z                # synthetic smoke test
```

The checker verifies each page's title and single heading, that every page's tags nest correctly, every local link and fragment, every HTML table row's final source cell, every Markdown table row in `docs/` for an HTTPS source on an approved official-source domain, and that no page on disk is missing from the checked set. It does not fetch external sites; each cited source must be reviewed directly (the review log is in `docs/source-verification.md`). The site's own code uses static HTML/CSS only, with no third-party scripts or cookies and no form or data collection. GitHub Pages is different: GitHub states that "when a GitHub Pages site is visited, the visitor's IP address is logged and stored for security purposes" ([GitHub Docs, What is GitHub Pages?](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)). This was flagged as T-03 on the Flagged for Review page.
