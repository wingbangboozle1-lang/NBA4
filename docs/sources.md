## Source-use rule

- Prefer direct NBA, Ksa, GitHub, NIST, or project-maintainer documentation. Do not substitute a secondary snippet for a primary record.
- Store retrieval/report time and exact source URL with each future data point. If the official or licensed source does not confirm a field, leave it blank and flag it **unverified**.
- Every source link above is a reference for manual review, not permission to reproduce its contents. In particular, NBA data-use restrictions are a blocking gate for sports-betting use.
- If a source page changes or disappears, preserve the original version only where its licence/terms permit; otherwise record the issue and do not silently replace it with an unofficial source.
