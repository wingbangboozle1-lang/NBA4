## Findings and disposition

- **IR-07 — G12 sample default (corrected; numeric policy remains open).** The validator previously displayed a proposed fixed minimum of 30 settled forecasts even though the policy left the value blank and no authorized power/precision analysis supported it. This audit removed that code default. `engine.cli validate` now reports `declared_minimum_sample_size=UNSET` unless a caller supplies a positive value; supplying a number alone does not pass G12. The policy remains blank pending a preregistered power/precision analysis on development data, not the final holdout. See [`docs/leaderboard.md`](leaderboard.md), [`engine/gates.py`](../engine/gates.py), [scikit-learn model evaluation](https://scikit-learn.org/stable/modules/model_evaluation.html), and [NIST bootstrap guidance](https://www.itl.nist.gov/div898/handbook/eda/section3/bootplot.htm).
- **IR-08 — five-game line/prop cutoffs (open).** `engine/ratings.py` and `engine/player_props.py` still apply a proposed five-game minimum. The value remains explicitly proposed and unvalidated in [`docs/engine.md`](engine.md); no authorized data or power/precision analysis supports treating five as an approved threshold. It must not be presented as a validated production policy.
- **IR-09 — leaderboard tie-break (open).** The policy document proposes ties by uncertainty-interval width and then preregistration time. `LeaderboardPolicy.tie_breaker` is checked for a non-empty string but `rank()` does not apply it; equal scores are ordered by strategy ID and model version. The current entry schema also lacks interval-width and preregistration-time fields. The documentation and public page now say this plainly; no ranking is published. Select and preregister a policy, represent the needed inputs, and implement/test it before ranking. See [`docs/correlation-and-leaderboard.md`](correlation-and-leaderboard.md), [`leaderboard.html`](../leaderboard.html), [`engine/leaderboard.py`](../engine/leaderboard.py), and [NIST bootstrap guidance](https://www.itl.nist.gov/div898/handbook/eda/section3/bootplot.htm).
- The duplicate Suggestions link in the README was consolidated. PR #18 already removed the repeated sidebar links and added checker guards; this audit retains those merged changes rather than duplicating them.
