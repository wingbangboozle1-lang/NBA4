# Suggestions register — choose the best path before implementation

**Purpose:** every change to this project should be chosen from explicit options, not improvised. This register lists each suggestion with its candidate paths, trade-offs, a recommended path (and why), the files it would touch, and a **Decision** column for the human reviewer. Nothing here is implemented until a decision is recorded. Nothing here is a legal opinion.

**How to use:** read a row, pick a path (or propose another), record it in the Decision column with a date and initials, and only then open the implementation work. All rows are **Pending** as of 2026-11-14.
