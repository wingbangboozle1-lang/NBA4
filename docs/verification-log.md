## Irregularities

These items were found during the independent re-verification pass. None of them changes a blocking conclusion; all are recorded for human review on the [Flagged for Review](../review.html) page.

- **I-1 · Injury snapshots roll quickly (timing, not an error).** The first audit recorded the 7:30 p.m. ET 2026-11-13 PDF as the latest report. At this session's check (2026-11-14 01:05 UTC = 8:05 p.m. ET), the official index already listed a newer **8:00 p.m. ET** report ([link](https://ak-static.cms.nba.com/referee/injury/Injury-Report_2026-11-13_08_00PM.pdf)), consistent with the league's "reports are updated on a continual basis" policy. Consequence: any future injury input must record both the report's own timestamp and an observed-at time, and treat older snapshots as stale. No status value from any snapshot is republished on this site.
- **I-2 · Pages build status is dynamic.** The Pages API reported `"status": "building"` at check time (PR #1 had just merged). The static configuration claim (main/root, legacy, HTTPS enforced) is verified; deployment success for a given commit must be re-checked after each merge (task J does this).
- **I-3 · Ksa advertising URL variants.** Some repository rows cite `kansspelautoriteit.nl/belangrijkste-regels-voor-kansspelreclame` and others cite `kansspelautoriteit.nl/voor-zakelijke-aanbieders/beperken-reclame/belangrijkste-regels-kansspelreclame-per/`. The second URL redirects to the first (canonical). Both are official Ksa pages and both resolve; citations are being normalized to the canonical URL during integration.
- **I-4 · Brier decomposition wording lives on the calibration guide.** The source register's ML-02 row attributed the reliability/resolution/uncertainty decomposition explanation to the model-evaluation guide. The exact explanatory sentence was confirmed on the official **calibration** guide (quoted above), while the model-evaluation guide confirms the Brier score's place among strictly consistent scoring functions and links the `#brier-score-loss` section. The register row was tightened to cite both pages precisely.
- **I-5 · FAQ contains dated statistical examples.** The NBA Stats FAQ (NBA-01) includes example tables "as of 3/19/2013" (e.g. a pace table). The register already notes these are not current values; this pass confirms the note is necessary — the FAQ's *policy* statements are current, its *numbers* are historical examples and are not used anywhere in this project.
