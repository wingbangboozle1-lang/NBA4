## Irregularities

Flagged, not blocking. Each is mirrored on the [Flagged for Review](../review.html) page.

- **V-01 · Terms §1 vs §9 tension (High, pre-existing).** Section 1 bars reproducing or publicly displaying "Basketball Content … except as provided in these Terms of Use", while §9(ii) permits NBA Statistics for "legitimate news reporting". The project's stance is to publish only dated, attributed, row-level factual observations with a link to the original official document, and to publish no NBA Statistics values, no model outputs and no picks. The owner alternative is a link-only site. Recorded as a reviewable decision, not a resolved legal question — [Terms](https://www.nba.com/termsofuse).
- **V-02 · Injury-PDF page-break extraction defect (Medium).** In the 2026-11-14 04:30 AM file the continuation rows for CHI@MIN, DET@MIA and the late 11/15 block lose their Game Date, Game Time and (for some rows) Team cells; the 11/13 07:30 PM file shows the same defect. Project rule: date/time/matchup may be filled only from the independent official schedule PDF with both sources cited in the row, and player-team cells stay blank and flagged unverified. — [04:30 AM PDF](https://ak-static.cms.nba.com/referee/injury/Injury-Report_2026-11-14_04_30AM.pdf) · [schedule PDF](https://cdn.nba.com/manage/2026/08/2026-27-NBA-Regular-Season-Schedule-By-Date.pdf).
- **V-03 · Ksa URL variants share one canonical page (Low).** `kansspelautoriteit.nl/voor-zakelijke-aanbieders/beperken-reclame/belangrijkste-regels-kansspelreclame-per/` resolves to the canonical `https://kansspelautoriteit.nl/belangrijkste-regels-voor-kansspelreclame`. The canonical URL is the one cited everywhere in this repository; no repository row cites the long variant. As the page itself notes, it is a summary and legislation controls. — [Ksa rules](https://kansspelautoriteit.nl/belangrijkste-regels-voor-kansspelreclame).
- **V-04 · Injury snapshots roll every 15 minutes (Medium, pre-existing VF-01/I-1).** A newer report always supersedes a pinned file, and a `NOT YET SUBMITTED` team row is a reporting state, not an absence of injuries. Every table row therefore carries the report's own header timestamp plus a fetched-at time, and the site never calls a file "latest". — [Injury report index](https://official.nba.com/nba-injury-report-2026-27-season/).
- **V-05 · `AccessDenied` on one URL form (Low).** `ak-static.cms.nba.com/wp-content/uploads/sites/4/2026/11/Injury-Report_2026-11-13_08_00PM.pdf` returns an S3 `AccessDenied` error, while the `ak-static.cms.nba.com/referee/injury/…` form serves the file. Only the working form is cited in this repository. — [working PDF](https://ak-static.cms.nba.com/referee/injury/Injury-Report_2026-11-13_08_00PM.pdf).
- **V-06 · scikit-learn docs are now 1.9.1 (Low).** Both pages checked this pass are the "1.9.1 (stable)" build. Wording of the quoted sentences is unchanged from the 1.x text cited earlier, but a version bump can reword documentation, so the version is recorded next to the quote. — [metrics and scoring](https://scikit-learn.org/stable/modules/model_evaluation.html).
