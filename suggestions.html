How to review

  1. Read the row and check the evidence link.
  2. Record Accept, Reject or Defer in the Decision column (or a note).
  3. Implement only the accepted rows, in the order agreed.
  4. Record the decision in the repository's coordination board so the change history stays traceable.

Open the register in the repository ↗

One rule for every suggestion

No suggestion may add a number that an official source does not support. Any value that cannot be confirmed from an official or authorised source stays blank and is flagged as unverified — that rule applies to the improvements as much as to the pages they would change.
